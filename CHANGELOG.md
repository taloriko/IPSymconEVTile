# Changelog

## 1.0 - 2026-09-06

- Initial release of EV Tile for IP-Symcon
- manufacturer-independent visualization architecture with MySkoda as the first fully supported data source
- automatic mapping by exact technical variable Ident with variable type validation
- manual per-data-point fallback mapping
- assignment status with automatically detected, manually assigned and missing data points
- optional grouped list view with links to the original vehicle variables after explicit user activation
- responsive single-tile vehicle overview using the IP-Symcon HTML SDK
- display-only tile; original variables and actions remain untouched
